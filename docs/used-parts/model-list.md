# รายชื่อรุ่นอะไหล่ที่ควรเพิ่ม (เน้นตลาดมือสอง)

รายการนี้เป็น**ชื่อรุ่นสำหรับเช็กลิสต์**เท่านั้น ไม่มีค่าสเปก ก่อนกรอกลงไฟล์ CSV ต้องเปิดหน้าเว็บผู้ผลิตของแต่ละรุ่น
แล้วกรอกสเปกตามนั้น (ดูคอลัมน์ใน `README.md`) ชื่อรุ่นเขียนจากความจำ จึงต้องเช็กชื่อเต็มกับเว็บผู้ผลิตด้วย
โดยเฉพาะเมนบอร์ดที่มีหลายรุ่นย่อยชื่อคล้ายกัน (WIFI / DDR4 / MAX / II)

รุ่นที่มีในระบบแล้วไม่ได้ใส่ซ้ำ (เช่น Core i5-14400F, Ryzen 5 7600X, B760M DS3H DDR4)

**ลำดับความสำคัญ:** ⭐ = รุ่นที่มีในตลาดมือสองไทยเยอะ ควรเพิ่มก่อน

**สถานะการขาย:** ช่อง `availability` ตัดสินจากร้านค้าตอนที่คุณสำรวจ ถ้าหาซื้อของใหม่ไม่ได้แล้วใส่ `มีแต่มือสอง`
ถ้ายังมีขายของใหม่ใส่ว่างไว้ (ราคาในช่อง price = ราคาของใหม่ตอนนี้)

> ⚠️ **ต้องเพิ่มเป็นคู่** CPU กับเมนบอร์ดของแพลตฟอร์มเดียวกัน ถ้าเพิ่ม CPU รุ่นเก่าแต่ไม่มีบอร์ดที่รองรับ ระบบจะจัดสเปกรุ่นนั้นไม่ได้
> และช่อง `generation` ของ CPU ต้องสะกดตรงกับรายการรุ่นที่บอร์ดรองรับ

## ลำดับการทำที่แนะนำ

1. **รอบแรก (เน้น ⭐):** CPU AM4 + Intel รุ่น 10–12 ประมาณ 12 รุ่น, บอร์ด B450/B550/H510/B560/H610/B660 ประมาณ 8 รุ่น,
   การ์ดจอ GTX 1660 Super / RTX 2060 / RTX 3060 / RX 580 / RX 6600 แค่นี้งบเล่นเกมมือสองก็ลงไปถึงระดับหมื่นต้น ๆ ได้แล้ว
2. นำเข้า แล้ว**สำรวจราคามือสองจริง**ของรุ่นที่เพิ่ง (หลังบ้าน → ราคามือสอง)
3. ลองจัดตามงบ 15,000 / 20,000 / 25,000 ดูว่าได้ชุดที่สมเหตุสมผลไหม
4. รอบต่อไปค่อยเพิ่มรุ่นที่เหลือ
