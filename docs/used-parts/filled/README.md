# ไฟล์ที่กรอกแล้ว พร้อมนำเข้า

## `cpu-used.csv` — CPU 98 รุ่น (AMD 46 · Intel 52)

นำเข้าที่ หลังบ้าน → นำเข้า CSV → หมวด CPU (ยี่ห้อ AMD และ Intel ต้องมีในระบบแล้ว)
นำเข้าซ้ำได้ ระบบจับคู่ยี่ห้อ+ชื่อรุ่นแล้วอัปเดตชิ้นเดิม

### แหล่งข้อมูล

| ข้อมูล | แหล่ง |
|---|---|
| สเปก AMD (Socket, คอร์/เธรด, คล็อก, TDP, กราฟิกในตัว, ชุดระบายความร้อนในกล่อง, ชนิดแรม, วันวางขาย) | หน้าสินค้าใน amd.com/en/support ของแต่ละรุ่น (ลิงก์อยู่ในช่อง `spec_source_url`) |
| สเปก Intel | Intel ARK หน้า specifications ของแต่ละ SKU (ลิงก์อยู่ในช่อง `spec_source_url`) |
| `price` | ราคาเปิดตัว (USD) × 35 ปัดหลักสิบ — Intel ใช้ Recommended Customer Price ตัวล่างจาก ARK, AMD และ Intel บางรุ่นที่ ARK ไม่แสดงราคา ใช้ราคาประกาศตอนเปิดตัว ใช้คิดค่าเสื่อมเท่านั้น ไม่ใช่ราคาที่ซื้อได้ |
| `perf_score` | PassMark CPU Mark (cpubenchmark.net/cpu-list) แปลงเป็นคะแนนด้วย `0.936 × (mark/1000)^1.279` ซึ่งฟิตจาก 5 รุ่นที่มีในระบบแล้ว (i5-14400F, i5-14400, 7600X, 9600X, 7800X3D) ใช้ถึง 7800X3D (= 86) · รุ่นที่ PassMark สูงกว่านั้นไล่เป็นเส้นตรงจาก 86 ถึง 100 (รุ่นที่ PassMark สูงสุด = 100) เพื่อไม่ให้รุ่นท็อปได้ 100 เท่ากันหมด |

### ข้อสังเกต

- `availability`: 33 รุ่น = มีขายมือหนึ่ง (รุ่นที่มีขายในหมวด CPU ของ advice.co.th วันที่ 14 พ.ย. 2026 และ `price` ของรุ่นเหล่านี้คือราคาหน้าเว็บร้านวันนั้น ใช้ราคากล่องผู้ผลิต ถ้ามีแต่กล่อง NEXT ของร้านใช้ราคานั้น) · อีก 65 รุ่น = มีแต่มือสอง (`price` = ราคาเปิดตัว) เช็กจากร้านเดียว ร้านอื่นอาจยังมีบางรุ่นขายอยู่
- `verified` = ตรวจแล้ว (ค่าสเปกมาจากหน้าผู้ผลิตโดยตรง)
- `includes_cooler` ของ Intel และ AMD บางรุ่นเว้นว่าง เพราะหน้าผู้ผลิตไม่ระบุ
- คะแนนช่วง 86–100 ถูกบีบให้แคบ (14 คะแนนสำหรับรุ่นท็อปทั้งหมด) ลำดับความแรงถูก แต่ระยะห่างจริงมากกว่าที่คะแนนบอก
- ยังไม่ใส่: Ryzen 5 3500X (ไม่มีหน้าใน amd.com), Ryzen 3 2200G และ Ryzen 5 9600 (หาราคาเปิดตัวที่ยืนยันได้ไม่เจอ)
- ยังต้องเพิ่ม **เมนบอร์ด** ที่รองรับ generation เหล่านี้ (Ryzen 1000–5000, Core 9th–11th Gen, Core Ultra 200S) ไม่งั้นจัดสเปกด้วย CPU รุ่นนั้นไม่ได้
- ราคามือสองจริงต้องสำรวจแล้วบันทึกที่ หลังบ้าน → ราคามือสอง

## `motherboard-used.csv` — เมนบอร์ด 50 รุ่น

ค่าสเปกมาจากไฟล์ที่เจ้าของโปรเจกต์รวบรวมเอง (ลิงก์ผู้ผลิตอยู่ในช่อง `spec_source_url`) ผมแก้ให้ใช้กับไฟล์ CPU ได้ 3 จุด:

- `Core Ultra (Series 2)` → `Core Ultra 200S` ให้ตรงกับ generation ใน `cpu-used.csv`
- รุ่นที่อยู่ในช่อง BIOS แล้ว เอาออกจาก `supported_generations` (X570: Ryzen 5000 · H610/B660/Z690: Core 13th/14th Gen) ไม่งั้นคำเตือน "ต้องอัปเดต BIOS ก่อน" ไม่ขึ้น
- เพิ่มคอลัมน์ `availability`: Socket AM4, LGA1151, LGA1200 = มีแต่มือสอง (34 รุ่น) · LGA1700, AM5, LGA1851 = มีขายมือหนึ่ง (16 รุ่น) ถ้ารุ่นไหนยังมีขายมือหนึ่ง แก้ทีละแถวได้

ยังว่าง: `release_year` ทุกแถว (ระบบคิดค่าเสื่อมเหมือนอายุ 1 ปี)

## `gpu-used.csv` — การ์ดจอ 78 รุ่น

ค่าสเปก (ความยาว ความหนา TBP ช่องไฟ ปีวางขาย) และราคาของรุ่นที่ยังขายมือหนึ่ง มาจากไฟล์ที่เจ้าของโปรเจกต์รวบรวมเอง (ลิงก์ผู้ผลิตอยู่ในช่อง `spec_source_url`) ยังไม่ได้เทียบกับหน้าผู้ผลิตทีละรุ่น ส่วนที่แก้:

- `availability` ใช้คำที่ระบบรับ (`มีขายมือหนึ่ง` / `มีแต่มือสอง`) และ `power_connectors` เป็นรูปแบบ `ชื่อ:จำนวน` เช่น `8pin:1|6pin:1`, `16pin:1`, `none:0`
- `chipset` ใช้ชื่อเต็มแบบเดียวกับการ์ดจอที่มีในระบบ เช่น `GeForce RTX 4060`, `Radeon RX 580 8GB`, `Intel Arc B580`
- `perf_score` = `0.794 × (PassMark G3D Mark/1000)^1.345` ฟิตจากการ์ดจอ 5 รุ่นที่มีในระบบ (RTX 5060 = 43, RTX 5060 Ti 8GB = 49, RX 9060 XT 16GB = 48, RTX 5070 = 65, RX 9070 XT = 77) คะแนนเดิมของ 5 รุ่นนั้นไม่ได้เรียงตาม PassMark เป๊ะ สูตรจึงคลาดได้ราว ±10 คะแนน (เช่น RTX 4070 ได้ 66 สูงกว่า RTX 5070 ที่มีอยู่เดิม 65 เล็กน้อย)
- สถานะมือหนึ่ง: คงไว้เฉพาะชิปที่ยังพบขายในหน้าการ์ดจอของ advice.co.th หรือ jib.co.th วันที่ 14 พ.ย. 2026 (RTX 3050 8GB, RTX 3060 12GB, RTX 4060, RTX 4060 Ti, RTX 4070, RTX 4080 Super, RX 7700 XT, RX 7800 XT, Arc B580) รวม 18 รุ่น เช็กระดับชิป ไม่ใช่รุ่นของยี่ห้อนั้นตรงตัว และหน้า JIB อาจรวมสินค้าที่หมดสต็อก
- ชิปที่ไฟล์เดิมระบุมือหนึ่งแต่ไม่พบขายในสองร้าน เปลี่ยนเป็นมีแต่มือสอง: RTX 4070 Super, RTX 4070 Ti Super, RX 6600, RX 6650 XT, RX 7600, RX 7900 GRE, Arc A750
- `price` ของรุ่นที่มีแต่มือสอง (60 รุ่น) = ราคาเปิดตัวของชิป (USD จากตารางในหน้า Wikipedia ของแต่ละซีรีส์) × 35 ปัดหลักสิบ ใช้คิดค่าเสื่อมเท่านั้น ราคามือสองที่อยู่ในไฟล์เดิมควรนำไปบันทึกที่ หลังบ้าน → ราคามือสอง

## `gpu-survey.csv` — ราคาสำรวจมือสองของการ์ดจอ 46 รุ่น

นำเข้าที่ หลังบ้าน → ราคามือสอง → "นำเข้าหลายรุ่นพร้อมกันจากไฟล์ CSV" (ต้องนำเข้า `gpu-used.csv` ก่อน)

- ราคามาจากช่อง `price` ของแถวที่ไฟล์เดิม (`gpu_updated.csv`) ระบุว่าเป็นมือสอง ไม่ได้สำรวจเพิ่ม
- ไฟล์เดิมมีราคาเดียวต่อรุ่น จึงใส่ `min_price` = `max_price`
- `grade` = B และ `surveyed_at` = 2026-11-14 เป็นค่าที่ตั้งตอนสร้างไฟล์ (ไฟล์เดิมไม่ได้ระบุเกรดและวันที่สำรวจ) แก้ในไฟล์ได้ก่อนนำเข้าถ้าไม่ตรง
- เกรด A และ C ระบบเทียบจากเกรด B ด้วยตัวคูณเกรดในหน้าตั้งค่า
- ราคาสำรวจใช้ได้ 90 วัน หลังจากนั้นระบบกลับไปใช้สูตรค่าเสื่อม ต้องสำรวจใหม่
- อีก 14 รุ่นที่มีแต่มือสอง (ชิปที่ไฟล์เดิมระบุมือหนึ่ง) ยังไม่มีราคาสำรวจ
