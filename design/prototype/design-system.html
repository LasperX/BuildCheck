Design System

ค่าออกแบบทั้งหมดของ BuildCheck ใช้เป็นต้นทางทั้งใน Figma และ Tailwind

แนวคิด

  • แผงหน้าปัดเครื่องมือ

    หน้าตาเหมือนเครื่องมือวัดที่เชื่อถือได้ พื้นเรียบ เส้นบาง ให้ตัวเลข เกจ และสถานะเป็นสิ่งที่เด่นที่สุดบนหน้า

  • สีต้องมีความหมาย

    น้ำเงินใช้กับสิ่งที่กดได้ แดง เหลือง เขียว ฟ้า ใช้กับสถานะเท่านั้น ม่วงใช้กับเรื่องมือสองเท่านั้น

  • สถานะไม่พึ่งสีอย่างเดียว

    ทุกสถานะมีไอคอนและข้อความกำกับ คนตาบอดสีและรูปขาวดำยังอ่านได้ครบ

สีสถานะ

ไอคอนจาก Lucide: circle-x, triangle-alert, circle-check, info ห้ามใช้สีเปล่าโดยไม่มีไอคอน

สีทั้งหมด

แต่ละช่องซ้าย = โหมดสว่าง ขวา = โหมดมืด ชื่อ token ใช้เป็นชื่อ Variable ใน Figma
