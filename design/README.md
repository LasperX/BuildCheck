# BuildCheck เฟส 0: ออกแบบ

ต้นแบบ HTML ที่กดดูได้ พร้อม Design System และสเปกสำหรับวาดต่อใน Figma

## วิธีเปิด

```bash
node design/serve.mjs
```

แล้วเปิด <http://localhost:4173> (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม แต่ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ ถ้าไม่ต่อจะเห็นฟอนต์สำรองของเครื่อง)

## หน้าควบคุมต้นแบบ (`index.html`)

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| Mockup / Wireframe | สลับระหว่างหน้าจริงกับโครงร่างขาวเทา โครงเดียวกันทุกระยะ |
| สว่าง / มืด | สลับโหมดสี |
| 1440 / 768 / 390 / 360 | ดูตามขนาดจอ ถ้าจอเล็กกว่าระบบจะย่อให้พอดี |
| วัดระยะ (Inspector) | ชี้ที่องค์ประกอบใดก็ได้ จะบอกขนาด padding gap มุมโค้ง สี ชื่อ token และฟอนต์ |
| สเปก | เปิดแผงสเปกของหน้านั้นด้านขวา |
| สถานการณ์ (ในแผงสเปก) | สลับสถานะของหน้า เช่น ผิดพลาด R01, ไฟไม่พอ, ผสมมือสอง |

## ไฟล์ Figma ตั้งต้น

<https://www.figma.com/design/AOJ9L4VFYk9BTPqSNA2m0A>

| หน้าใน Figma | เฟรม |
|---|---|
| Foundations | Design System |
| Pages | หน้าแรก, จัดสเปก, หน้าต่างเลือกอะไหล่, จัดสเปกตามงบ, รายละเอียดอะไหล่, รายละเอียดสเปก, Dashboard |
| Mobile | จัดสเปก 390 |

เป็นเลเยอร์ที่แก้ได้ แต่สียังเป็นค่าตายตัว ไม่ได้ผูกกับ Variable และยังไม่ได้แยกเป็น Component

Variable สีมี 47 ตัว ระบบ Starter ให้ได้ 1 Mode ต่อ Collection จึงแยกเป็น 2 Collection คือ `Color` (สว่าง) และ `Color (Dark)` (มืด)

**งานที่เหลือให้ทำเองใน Figma** เพราะโควต้า MCP ของแผน Starter หมดระหว่างทำ

1. ในหน้า Pages ตั้งชื่อเฟรม `05-budget`, `06-part-used`, `08-admin` และจัดตำแหน่ง ถ้าทับกับเฟรมอื่นให้ลากออก
2. ในเฟรม 3 ตัวนั้นและเฟรม Design System เลือกป้ายบนกราฟและเกจที่เป็นฟอนต์ Inter แล้วเปลี่ยนเป็น IBM Plex Sans Thai (ตัวเลข 70 และ 85 บนเกจใช้ IBM Plex Mono)
3. ถ้าไอคอนแว่นขยายถูกช่องค้นหาบังในเฟรม `05-budget`, `06-part-used` และ Design System ให้เลื่อนเลเยอร์ไอคอนขึ้นบนช่องกรอก

## วาดต่อใน Figma

1. อ่าน `prototype/specs.html` (สั่งพิมพ์เป็น PDF ได้) หรือแผงสเปกในหน้าควบคุม
2. สร้าง Variable จาก `tokens.json` ซึ่งมีค่าสว่างและมืดของทุกสี ยังไม่ได้ทดสอบการนำเข้าด้วยปลั๊กอินจริง ถ้านำเข้าไม่ได้ให้กรอกเองตามชื่อ token
3. ลงฟอนต์ IBM Plex Sans Thai และ IBM Plex Mono จาก Google Fonts แล้วสร้าง Text Style ตามหน้า Design System
4. ติดตั้งปลั๊กอิน Lucide สำหรับไอคอน
5. วาดคอมโพเนนต์เล็กก่อน แล้วใช้ Inspector เช็กระยะของจริงจากต้นแบบ

## ข้อมูลในต้นแบบ

- ชื่อรุ่น ยี่ห้อ สเปก ราคา ชื่อผู้ใช้ คอมเมนต์ และสถิติทั้งหมดเป็น**ข้อมูลสมมติ** ไม่ใช่ข้อมูลอะไหล่จริงและห้ามใส่ในรูปเล่ม
- ตัวเลขที่มาจากเอกสาร: สูตรวัตต์ 372 W → PSU 500 W, สูตรค่าเสื่อม 12,000 → 6,100 บาท, สัดส่วนงบ, ข้อความกฎ
- ข้อความ R01 ที่มีชื่อรุ่นจริงในหน้า Design System คัดมาจากเอกสารหัวข้อ 4.1
- ตรรกะใน `assets/proto-engine.js` เป็นตัวอย่างบางกฎเพื่อโชว์หน้าจอ Engine จริงจะเขียนใหม่ในเฟส 6 พร้อม Unit test
- QR Code เป็นภาพตัวอย่าง สแกนไม่ได้จริง

## ที่ตรวจแล้วและยังไม่ได้ตรวจ

| ตรวจแล้ว | ยังไม่ได้ตรวจ |
|---|---|
| Contrast 27 คู่สี ผ่าน WCAG ทั้งสว่างและมืด (ดูตารางในหน้า Design System) | โปรแกรมอ่านหน้าจอและการตรวจด้วย axe (เฟส 13) |
| สีกราฟผ่าน validator แยกสีได้สำหรับคนตาบอดสี | Lighthouse (เฟส 13) |
| ไม่ล้นแนวนอนที่จอ 360 ทุกหน้า | มือถือจริง, Safari, Firefox |
| กดใช้งานบน Edge headless และ Browser pane ไม่พบ Error | เกจและเกณฑ์ไฟยังใช้ค่าตามเอกสาร รอ Q2 |

หน้าอื่นในผังเว็บ 31 หน้า เช่น คลังอะไหล่ ชุมชน ล็อกอิน และหลังบ้านส่วนที่เหลือ ใช้คอมโพเนนต์ชุดนี้ และจะออกแบบรายละเอียดในเฟสของหน้านั้น
